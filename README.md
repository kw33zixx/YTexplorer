# 📼 YouTube's Trash Bin & Graveyard Explorer

Веб-приложение для исследования глубин YouTube и поиска совершенно неизвестных видеороликов (0–30 просмотров), загруженных без описаний, тегов и нормальных названий прямо со старых телефонов, мыльниц, видеоредакторов и веб-камер.

В основе проекта лежит исследование **KVN AUST: YouTube’s Recycle Bin & The internet’s largest video graveyard (450+ шаблонов и лидов)**.

---

### 🚀 Быстрый запуск

1. Убедитесь, что установлены зависимости:
   ```bash
   pip install fastapi uvicorn yt-dlp
   ```
2. Запустите приложение двойным кликом по `start.bat` или командой:
   ```bash
   py -m uvicorn app:app --port 8000 --reload
   ```
3. Откройте в браузере: [http://localhost:8000](http://localhost:8000)

---

### ✨ Возможности

- **3 эпохи поиска (Maps):**
  - 🟢 **Map 1: Свежие видео (~0 просмотров)** — современные смартфоны, стримы, скринкасты, сортировка по дате загрузки (`Upload Date`).
  - 🟡 **Map 2: Забытое кладбище (2008–2020)** — культовые мыльницы Canon, Sony, Casio, Nikon, первые GoPro, дроны, Windows Movie Maker.
  - 🔴 **Map 3: Доисторическое ретро (2006–2008)** — кнопочные телефоны, формат 3GP, оператор `before:2008`.
- **Категории устройств:**
  - 📱 Смартфоны (iPhone `IMG`, Android `VID`)
  - 📷 Цифровые камеры (`DSC`, `MVI`, `SAM`, `PICT`)
  - 🛹 Экшн-камеры и дроны (`GOPR`, `DJI`, `FILE`)
  - ✂️ Видеоредакторы (`My Movie`, `My Slideshow`, `Clipchamp`)
  - 🎙️ Веб-камеры и скринкасты (`WIN YYYYMMDD`, `OBS`, `Zoom`)
  - 🇷🇺 Русскоязычные артефакты (`ВидеоXXXX`, `Фильм 0XXX`, `копия видео`)
- **Встроенный плеер YouTube:** просмотр прямо на сайте без перехода на YouTube.
- **🎰 Рулетка:** моментальный поиск и запуск случайного затерянного ролика в 1 клик.
- **⭐ Избранное:** локальное сохранение редких находок.
- **Прямая ссылка:** кнопка перехода в YouTube с уже настроенными точными поисковыми фильтрами.
